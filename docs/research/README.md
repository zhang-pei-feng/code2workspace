# Research Docs

This section is the index for thesis-facing material. The detailed thesis drafts
stay close to the harness experiment code under `experiments/harness/`, while
`docs/research/` keeps the stable entry points and progress log.

## Core entries

- `docs/research/thesis-log.md`
  - dated research and writing chronology
- `experiments/harness/THESIS_METHOD.md`
  - method-oriented explanation of the harness design
- `experiments/harness/THESIS_CHAPTER_ZH.md`
  - Chinese thesis-style chapter draft for the harness method
- `experiments/harness/THESIS_OUTLINE_ZH.md`
  - full thesis outline and chapter mapping
- `experiments/harness/THESIS_EXPERIMENT_DESIGN_ZH.md`
  - completed vs planned experiment design
- `experiments/harness/THESIS_FULL_DRAFT_ZH.md`
  - current end-to-end Chinese manuscript draft
- `experiments/harness/THESIS_ASSET_MATRIX_ZH.md`
  - figure and table tracking matrix
- `experiments/harness/THESIS_APPENDIX_TEMPLATES_ZH.md`
  - appendix templates for experiment evidence

## Relationship To Engineering Docs

- `docs/overview/current-status.md` is the best engineering status summary.
- `docs/overview/roadmap.md` is the current implementation target.
- `docs/research/thesis-log.md` explains how engineering progress maps to thesis
  claims and evidence.
