# Epidemic Warning Report Structure

Use this outline when the user asks for a fuller report rather than a short
brief.

## Core sections

1. Executive Summary
2. Monitoring Overview
3. Key Risk Signals
4. Variant / Pathogen Notes
5. Prevention and Preparedness Actions
6. Uncertainty and Data Gaps
7. Sources

## Recommended evidence mapping

- Monitoring Overview:
  official surveillance, fixed-source fetchers, or wide-monitor outputs
- Key Risk Signals:
  trend changes, severity changes, geographic spread, variant shifts
- Variant / Pathogen Notes:
  local DB mutation evidence, lineage definitions, risk scores
- Prevention and Preparedness Actions:
  sequencing, surveillance escalation, clinical readiness, communication
- Sources:
  actual skills and source URLs used in this report only

## Style

- Start with the report directory path
- Keep the top summary actionable
- Separate evidence from speculation
- If a signal is weak or incomplete, label it as uncertain
- Do not turn local mutation evidence directly into clinical claims without
  literature or official support
