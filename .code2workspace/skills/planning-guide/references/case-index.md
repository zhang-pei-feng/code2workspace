# Planning Case Index

这些案例是给智能体和开发者看的规划样板，不是执行测例。

用途：

- 快速找到和当前任务最接近的规划形状
- 先决定证据来源，再决定执行动作
- 明确验证口径和失败边界，避免一上来就误用工具

首批场景：

- [本地数据库检索型](./case-local-database-query.md)
- [官方监测时效型](./case-official-monitoring-window.md)
- [最新论文检索型](./case-latest-literature-search.md)
- [跨源综合研判型](./case-cross-source-synthesis.md)

建议用法：

1. 先读 `checklist.md`，锁定目标、约束和验证方式。
2. 再读 `source-selection.md`，确定先查本地还是先查外部。
3. 最后套用最接近的案例结构，避免把时效问题、本地问题和综合研判问题混成一个动作。
