# Planning Checklist

Use this checklist before you start executing a complex or uncertain task.

## Goal

- What is the required outcome?
- What counts as success?
- What is out of scope?

## Constraints

- What constraints already exist?
- What assumptions are you making?
- What would make the current approach risky or wasteful?

## Available facts

- What can be discovered locally right now?
- Which files, logs, configs, tests, schemas, or datasets are likely sources of truth?

## Missing information

- What facts are still missing?
- Which missing facts are necessary before implementation or conclusions?
- Which of those facts require external evidence rather than local inspection?

## Source choice

- Which sources are cheapest and most authoritative?
- Should you start with repository evidence, local data, official docs, a database, a monitoring site, or current web research?
- Are you choosing a source because it is convenient, or because it is the right source?

## Execution order

- What order minimizes wasted work?
- What should be verified before doing irreversible or expensive steps?
- What intermediate checkpoints would tell you the plan is wrong early?

## Verification

- How will you prove the answer, code change, or report is correct?
- What command, artifact, or evidence will you use to verify completion?
