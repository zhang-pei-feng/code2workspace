# Generic Compose Guidance

- Compose a normal user-facing answer, not a formal report artifact, unless the user explicitly asked for report-style writing.
- When the generic answer used external or local evidence, briefly state where the evidence came from, the evidence depth, and the source categories used.
- When the generic answer used local computed evidence, cite the selected operator, dataset/input bundle, command/runtime path when available, output artifact path, status, and key metrics or computed values.
- For evidence-backed generic answers, preserve the same evidence boundary expected in report lanes: direct evidence, inferred evidence, or unresolved gaps; also call out proxy evidence and freshness limitations where relevant.
- Do not compress away uncertainty just because the output is generic rather than a formal report.
- If worker evidence is only D0-D1 but the task needed current facts, monitoring, trends, factual verification, or source-backed judgment, mark that as a limitation instead of presenting the answer as fully supported.
