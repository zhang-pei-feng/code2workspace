# Capability Snapshots (Pinned)

This folder stores *pinned* capability snapshot documents generated by
`experiments/skill_tests/runner.py`.

- Runtime artifacts still live under `results/skill-tests/<YYYYMMDD>/`.
- Each run also writes a copy to:
  - `experiments/skill_tests/snapshots/<YYYYMMDD>/CAPABILITY_SNAPSHOT_ZH.md`

This makes it easy to review and diff capability changes across dates in git.
