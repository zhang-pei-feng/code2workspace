# COVID Monitoring Questions Batch

本批次用于评测 `code2workspace` 在不显式提示 skills 的情况下，对近期新冠、
流感、RSV 相关自然语言问题的直接回答效果。

## Cases

- `covid-monitoring-01-next-covid-flu-peak.toml`: 下一波新冠/流感阳性率的高峰会在什么时间？
- `covid-monitoring-02-spring-travel-covid-spread.toml`: 2026 年初的春运人口流动是否促进了新冠传播？
- `covid-monitoring-03-guangzhou-event-covid-impact.toml`: 我想 2026 年8 月在广州举办一次大型运动会，是否会受到新冠的影响？
- `covid-monitoring-04-clinical-vs-wastewater-trends.toml`: 临床阳性率趋势与污水监测趋势是否一致？
- `covid-monitoring-05-ba32-vs-xfg-severity.toml`: BA.3.2 和 XFG 毒株的子代中，哪一种会导致临床重症率增加？
- `covid-monitoring-06-ba32-vaccine-trials.toml`: 近期是否有新的针对新冠 BA.3.2 的疫苗进入临床试验？
- `covid-monitoring-07-covid-flu-correlation-seasonality.toml`: 历年新冠和流感阳性率是否有相关关系？新冠阳性率的波动周期有什么规律？是否和季节有关？
- `covid-monitoring-08-may-mainland-dominant-lineage.toml`: 今年 5 月，中国大陆的主要流行新冠毒株（占比最高的毒株）会是哪一株？
- `covid-monitoring-09-fastest-growing-sublineage.toml`: 近两周增长最快的亚型及其序列数有多少？
- `covid-monitoring-10-s-protein-escape-sites.toml`: 新冠病毒S蛋白上哪些位点的突变最容易逃逸抗体？
- `covid-monitoring-11-us-trend-deaths-ed-positivity.toml`: 讲一下美国新冠疫情的趋势，最近一个月美国的新冠死亡率、急诊科就诊人数和检测阳性率变化情况如何？
- `covid-monitoring-12-covid-flu-rsv-overview.toml`: 帮我看一下近期 COVID、流感和 RSV 的监测情况。
